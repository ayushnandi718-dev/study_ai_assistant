🚀 AI Career Mentor & Study Coach

«An intelligent AI-powered mentor built using Ollama, Mistral, Python, and Streamlit that helps students learn faster, plan smarter, and grow consistently.»

---

🌟 Vision

Most AI assistants answer questions.

This project goes one step further.

AI Career Mentor & Study Coach is designed to guide students through their learning journey by providing personalized explanations, study strategies, career insights, productivity tips, and actionable roadmaps.

The goal is simple:

«Transform AI from a chatbot into a mentor.»

---

🎯 Problem Statement

Students often struggle with:

- Information overload
- Lack of structured guidance
- Career uncertainty
- Poor study planning
- Difficulty understanding complex concepts

This project addresses these challenges through a locally hosted Large Language Model (LLM) that provides instant, intelligent, and personalized assistance.

⚙️ Installation

Clone Repository

git clone <repository-url>
cd AI_Career_Mentor

Create Virtual Environment

python -m venv venv

Activate Environment

venv\Scripts\activate

Install Dependencies

pip install -r requirements.txt

Run Ollama

ollama run mistral

Launch Application

streamlit run app.py
